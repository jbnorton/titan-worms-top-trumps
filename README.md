# Worms 2: Armageddon — Top Trumps (fan-made)

A free single-player Top Trumps game featuring 23 custom cards. Original uploaded card art is preserved.

## Play on GitHub Pages
1. Create a **public** GitHub repository (e.g. `worms-top-trumps`).
2. Upload **all contents** of this folder to the repository root (`index.html`, `style.css`, `game.js`, `cards.json`, and `cards/`).
3. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. After deployment, open the URL shown on the Pages settings screen.

## Rules
Cards are shuffled and dealt alternately (12 vs 11). The current round's controlling player chooses a statistic; CPU picks its highest stat on its turns. Higher wins both cards and any tied pot, and controls the next round. Equal scores send both cards to a pot until a subsequent decisive round. Win by collecting every card.
